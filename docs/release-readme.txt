Vobot Now Playing
=================

This archive contains both halves of the project, matched to each other. The
ambient light feature needs both, so install the dock app as well as the client.

  Vobot Now Playing\
      The Windows client. Unpack anywhere and run "Vobot Now Playing.exe".
      There is no installer.

  win_now_playing\
      The Mini Dock app. Copy this whole folder into the apps\ folder on your
      dock, using Thonny or the dock's own app manager. Restart the dock, then
      open "Windows Now Playing" from its app menu.

On first run the client searches the network and configures itself. If it
cannot find the dock, set the address by hand in Settings.

Each folder contains the licence that covers it: the Windows client is under
the GNU GPL v3, and the Mini Dock app is under the MIT licence.
